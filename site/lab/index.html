The lab in your browser

Run the solvers here, on this device.

The same C code as the app, compiled to WebAssembly. Pick a scenario, change what it lets you change, and run it: the physics is computed in this page, on your phone or computer, and nothing is sent anywhere. Drag the result to turn it.

Scenario

Loading the lab

This browser cannot run WebAssembly in a background worker, which the lab needs. Any current version of Safari, Chrome, Firefox or Edge can.

What runs here, and what does not

The app's solvers, made smaller so that a phone can run them.

The same code

Every scenario runs through the lab's own C solvers and renderer, compiled from the repository to WebAssembly with IEEE arithmetic, as the app builds them. The numbers the solver reports are under the picture.

Smaller than the app

Here the lab runs on one processor core and without a GPU, so each scenario is coarser or shorter than the app's own, and says by how much. The app runs them at full size, on every core, and on the GPU where a solver has a GPU engine.

Nothing leaves the page

The scenario, the run and the result stay in this browser tab and are gone when it closes. The page sets no cookies and sends nothing anywhere.
