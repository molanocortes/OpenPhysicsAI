## Third-party software

**Runtime:** none. The binaries are built from the NAVIER sources alone and link only against the operating system's
C library, math library and threads. There is no bundled JSON, mesh, linear-algebra or networking library. `navier-ctl
doctor` confirms that only system libraries are loaded.

**Build:** Apple clang (Xcode command-line tools) and `make`.

**Optional tools, not bundled** (each keeps its own licence):

| Tool | Used by | Licence (upstream) |
|---|---|---|
| Python 3 | `share/navier/tests/studyflow.py`, `share/navier/examples/bracket_comparison/make_geometry.py` | PSF licence |
| NumPy | `share/navier/tools/ccx_crosscheck.py` | BSD-3-Clause |
| CalculiX (`ccx`) | the independent cross-check | GPL-2.0 |
| an MCP client (Claude Code, Codex, ...) | driving the workflow with an AI model | the client's own terms |

## Data

- **Material library:** the embedded records hold demonstration values that do not describe a real grade.
- **Example material:** the aluminium values of the example are nominal handbook magnitudes entered by hand, not a
  copy of a datasheet.
- **Geometry:** the example brackets and the user-test plates were generated by scripts in this package
  (`make_geometry.py`, `make_task_geometry.py`).

The inventory of every item, and the licensing decisions still open, are listed in the source tree
(`release/DISTRIBUTION_INVENTORY.md`).
